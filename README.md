# Moon png talking 1.0

![Цветочек](images/flower.png)

Маленькая программа, которая позволяет выводить на ваш рабочий стол говорящего компаньона!

> Изначальная программа была сделана за 4 дня, но я её дорабатывал ;)

## Особенности

- Относительно лёгок в использовании
- Весит крайне мало
- Полностью бесплатен!

## Инструкция

Для изменения настроек, заданных по умолчанию, вам потребуется открыть usrsettings.txt и изменить значения:

| Обозначение | Что это? |
| ----- | ------- |
| widthscreen | ширина окна |
| heightscreen | высота окна |
| mouthposx | точка позиции рта (x) |
| mouthposy | точка позиции рта (y) |
| mouthwidth | длина рта |
| mouthheight | максимальная высота рта |
| filename | название файла или путь к нему |

Все значения (кроме __filename__) принимают числа больше 0.\
__filename__ принимает строку.
